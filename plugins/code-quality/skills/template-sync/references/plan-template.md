### <last>. Record the sync

Once every step above is applied or deliberately skipped, close with the sync
commit. Its `Template-Sync` trailer is where the next run starts.

```bash
git commit --allow-empty -F - <<'EOF'
chore: sync with template <OWNER/NAME> @ <head short>

Template <OWNER/NAME> (<ref>): <anchor short>..<head short>, <N> commits.

Template-Sync: <head, full SHA>
Template-Source: <OWNER/NAME>
Template-Ref: <ref>
Template-Skipped: <path> -- <reason, one trailer per skipped file>
EOF
```

<If `.template-sync.json` exists: "`git rm .template-sync.json` in the same
commit; the trailers replace it.">

If only part of the plan is applied, make no sync commit: the next run starts
from the old anchor and sees the applied part as already done.
