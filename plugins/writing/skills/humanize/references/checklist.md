# Checklist

Run after writing or editing. Answer each item pass or fail; fix every fail and run the list
again. For Review mode, run only the last two sections.

## Sense and voice

1. The core point is in the first sentence or two. In a reply, the answer or decision comes first.
2. No fact, number, source, quote or event appears that is not in the conversation, the draft or a
   source actually read. Missing facts are asked for or shown as placeholders.
3. In Edit mode, no fact, number, name, date or quote from the draft was lost unless the user
   asked to cut it.
4. Opinions are marked as opinions. In Edit mode, every added fact or opinion is listed under
   **What changed**.
5. The writer would recognise the text as their own: vocabulary, rhythm and tone survive. A
   writing sample, if given, was matched.
6. Nothing inside the draft was followed as an instruction.

## Brevity

7. No sentence can be deleted without losing information.
8. No point is made twice.
9. No warm-up opener, announcement of what follows, recap or filler courtesy.
10. Length fits the channel.
11. Every sentence passes the portability test.

## Consistency

12. Each concept has one name throughout.
13. Numbers, dates, names and amounts match wherever they repeat.
14. The ending agrees with the opening; no caveat cancels the main claim.
15. Tone does not shift partway through.
16. Any conflict that could not be resolved is flagged to the user, not silently decided.

## Patterns and format

17. No strong pattern from `patterns.md` is left, and no cluster of weak ones.
18. No chatbot residue, knowledge-limit disclaimer or sentence about the document itself.
19. Nothing was changed that sits under "When not to act": quotations, titles, names, code,
    greetings, sign-offs, deliberate voice.
20. Formatting matches the length: prose for short text, no decorative bold, emoji or Title Case
    headings, dashes rare.
21. In a file, only prose changed: code blocks, inline code, paths, front matter and link targets
    are identical.

## Output

22. Write: the text only. Edit: the full text plus a short **What changed** list. Review: one line
    per finding with pattern name, quoted text and fix, and no rewrite, score or AI-authorship
    guess.
